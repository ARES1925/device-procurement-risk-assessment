# Probabilistic Risk Assessment for Device Procurement

## Overview
This repository contains a probabilistic risk assessment report and mathematical model drafted for upper management. Based on 20 years of historical manufacturing test parameters, the objective was to evaluate vendor reliability and recommend a "go/no-go" decision for a $20M capital investment.

## Core Objectives & Methodology
* **Statistical Computation:** Calculated complex joint, marginal, and conditional probabilities to evaluate the reliability of vendor-supplied defect testing.
* **Data Integrity Analysis:** Evaluated the provided test metrics (e.g., false positive and false negative rates) using MATLAB to determine if the vendor's research data was statistically sound and trustworthy.
* **Executive Decision Making:** Synthesized the mathematical findings into a finalized, data-driven recommendation regarding the $20M device procurement.

## Core Skills
* Applied Probability, Risk Analysis, Set Theory, MATLAB Simulation, Executive Reporting

## Repository Contents
* `Procurement_Risk_Report.pdf` - The final executive report detailing the analysis of any systemic testing flaws and the final investment recommendation.
* `procurement_risk_analysis.m` - The MATLAB script used to compute the required conditional, joint, and marginal probabilities, executing the logical bounds for the final decision.
